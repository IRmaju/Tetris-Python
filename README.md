# Tetris Game 

This is a simple Tetris game built using Python and Streamlit. It features basic gameplay elements of Tetris, such as falling blocks, rotation, and movement. The game uses emojis for rendering blocks and provides interactive buttons to control the game.

## Features

- **Random Tetrominoes**: The game randomly generates different Tetris shapes (I, O, T).
- **Interactive Controls**: Use buttons to move the pieces left, right, down, and rotate.
- **Game Over**: The game ends when a new piece cannot be placed on the grid.
- **Visual Appeal**: The game uses colorful emojis for the pieces to make the grid visually engaging.
